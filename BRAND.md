# Stellara — Brand Brief

A kickoff-ready reference for advertising and marketing design partners. All color, type, and
theme values are pulled directly from the production codebase (`app/globals.css`,
`app/layout.tsx`, and the brand assets in `public/`).

## 2. Color Palette (exact hex)

**Signature — Starlight Gold (the single brand accent)**

| Role | Light mode | Dark mode |
|---|---|---|
| Brand / primary | `#A8792A` | `#E8C88A` |
| Brand strong | `#8F651F` | `#F0D9A8` |
| Brand tint (fill) | `#F6ECD6` | `#241F12` |
| Brand tint strong | `#EFE0C2` | `#2B2514` |

**Neutrals**

| Role | Light | Dark |
|---|---|---|
| Background / paper | `#F7F8FB` | `#0A0E1A` |
| Foreground (ink text) | `#12172A` | `#EEF1F7` |
| Card surface | `#FFFFFF` | `#111726` |
| Muted text | `#5C6172` | `#9AA0B2` |
| Border | `#E2E4EC` | `rgba(255,255,255,0.09)` |
| Deep "ink" feature surface | `#070B16` | `#070A14` |

**Status accents** (secondary — UI labels only, use sparingly in brand work)

- Done / green `#12A150` · Working / amber `#C98A1E` · Stuck / red `#E2445C` · Info / blue `#3E7BFA`
- Destructive / error: `#E2445C` (light) / `#FF6B7F` (dark)

> **Core rule:** one accent (gold) only. Everything else is neutral. Do not introduce
> additional brand hues.

## 3. Typography

| Role | Typeface | Weights |
|---|---|---|
| Display / headlines | Space Grotesk | 500, 600, 700 |
| Body / UI | Manrope | 400, 500, 600, 700, 800 |

## 5. Visual Language / Art Direction

- **Aesthetic:** precise, engineered, editorial — "engineering-grid meets celestial."
- **Signature motifs:** hairline corner ticks on focal surfaces; a gold dot traveling a connector
  line (work moving from source to action); soft elevated card shadows.
- **Corner radii scale:** 8 / 12 / 16 / 20 / 24 px.
- **Avoid:** decorative gradients, glow blobs, heavy skeuomorphic shadows, emojis as icons.
- **Motion:** one orchestrated entrance sequence with staggered reveals; always honor
  reduced-motion preferences.

---

## 6. Voice & Messaging

- Confident, plain-spoken, outcome-focused; anti-hype.
- Value pillars: Capture → Convert → Operate → Retain → Grow.
- Any sample metrics in marketing must be labeled "Illustrative" — never presented as real
  client results.

---

## 7. Assets to Request From the Design Partner

- Finalized logo/icon motif, then a full lockup suite: horizontal, stacked, icon-only,
  mono/knockout, in light + dark.
- Clear-space and minimum-size rules; favicon / app-icon set (16–512px, plus maskable).
- Social avatars + OG/share templates (OG image spec: 1200×630).
- Brand guidelines PDF covering the palette, type scale, and motif usage above.
- Editable source files (Figma library + design tokens matching the variables in this repo).
